# avocado-price-prediction-and-classification.
Data analysis and machine learning project on avocado dataset analysis featuring data cleaning, EDA, Linear Regression, Logistic Regression, and PCA.


🥑 Avocado Price Prediction and Classification

Project Overview

This project explores avocado market data using Data Analytics and Machine Learning techniques in Python. The analysis focuses on predicting avocado prices and classifying avocado categories using multiple machine learning models.

The project combines:
	•	Time Series Analysis
	•	Linear Regression
	•	Logistic Regression
	•	PCA + Logistic Regression

to uncover trends, patterns, and predictive insights from real-world avocado sales data.

⸻

📌 Objectives

Price Prediction
	•	Analyze avocado price trends over time
	•	Identify seasonal patterns in avocado prices
	•	Predict avocado prices using Linear Regression
	•	Visualize trends with Time Series Analysis

Classification
	•	Classify avocado categories using Logistic Regression
	•	Improve classification performance using PCA + Logistic Regression
	•	Evaluate model performance using standard classification metrics

📈 Price Prediction Models

Time Series Analysis

Used to analyze avocado price movement and seasonal trends over time.

Linear Regression

Built a regression model to predict avocado prices based on selected features.

Key Insights
	•	Organic avocados generally had higher prices
	•	Prices showed seasonal fluctuations
	•	Some regions experienced higher price volatility

⸻

🤖 Classification Models

Logistic Regression

Used to classify avocado categories based on dataset features.

PCA + Logistic Regression

Applied Principal Component Analysis (PCA) to reduce dimensionality before classification.

Evaluation Metrics
	•	Accuracy
	•	Precision
	•	Recall
	•	F1-Score
	•	Confusion Matrix

Key Insights
	•	Logistic Regression performed effectively for classification
	•	PCA helped simplify the feature space while maintaining model performance
